# 🎨 Sketch

Sketch is an Android drawing app that lets users import images from the gallery, draw on them, and save the edited images back to their device.

---

## 🚀 Features

* 🖼️ Import images from gallery
* ✏️ Draw on images
* 💾 Save edited images
* ⚡ Lightweight and fast

---

## 🛠️ Tech Stack

* Kotlin
* Android SDK
* XML UI

---

## 📦 Installation

```bash
git clone https://github.com/Dhairya329/DrawApp.git
```

Open in Android Studio and run my app.
